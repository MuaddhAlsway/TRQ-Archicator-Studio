## 🎯 COMMON TASKS

### Task 1: Add a New Project (English)

1. Click **"Projects (EN)"** in sidebar
2. Click **"+ Add Project"** button
3. Fill in:
   - **Title:** Project name
   - **Category:** Select category
   - **Description:** Short description
   - **Image:** Upload cover image
   - **Gallery:** Upload multiple images
   - **Location:** Project location
   - **Client:** Client name
   - **Year:** Project year
   - **Detailed Description:** Full description
   - **Challenge:** What was the challenge?
   - **Solution:** How did you solve it?
   - **Features:** List key features
   - **Materials:** List materials used
4. Click **"Save Project"**
5. Project appears on frontend immediately

### Task 2: Add Arabic Version of Project

1. Click **"Projects (AR)"** in sidebar
2. Click **"+ Add Project"** button
3. Fill in same fields but in **Arabic** (RTL)
4. Click **"Save Project"**
5. When user switches to Arabic on frontend, they see this version

### Task 3: Update Homepage Text (English)

1. Click **"Site Settings (EN)"** in sidebar
2. Click **"Home Intro"** tab
3. Edit:
   - **Title:** Main heading
   - **Text 1:** First paragraph
   - **Text 2:** Second paragraph
   - **Image:** Homepage image
   - **Link Text:** Button text
4. Click **"Save Settings"**
5. Changes appear on homepage immediately

### Task 4: Update Homepage Text (Arabic)

1. Click **"Site Settings (AR)"** in sidebar
2. Click **"Home Intro"** tab
3. Edit same fields in **Arabic**
4. Click **"Save Settings"**
5. Arabic users see updated text

### Task 5: Add Hero Slide

1. Click **"Hero Slides (EN)"** or **"Hero Slides (AR)"**
2. Click **"+ Add Slide"** button
3. Fill in:
   - **Title:** Slide title
   - **Description:** Slide description
   - **Image:** Background image
   - **Video:** Optional video
   - **Button Text:** CTA button text
4. Click **"Save Slide"**
5. Slide appears on homepage

### Task 6: Publish/Unpublish Content

1. Find the project/article in the list
2. Click the **eye icon** to toggle visibility
3. **Eye open** = Published (visible on frontend)
4. **Eye closed** = Draft (hidden from frontend)

### Task 7: Delete Content

1. Find the item in the list
2. Click the **trash icon**
3. Confirm deletion
4. Item is removed

## 🖼️ IMAGE UPLOAD

### How to Upload Images

1. Click **"Choose Image"** or **"Upload"** button
2. Select image from your computer
3. Wait for upload to complete
4. Image URL appears automatically
5. Click **"Save"** to confirm

### Supported Formats
- JPG / JPEG
- PNG
- WebP
- GIF

### Image Size Recommendations
- **Hero slides:** 1920x1080px
- **Project cover:** 800x600px
- **Gallery images:** 1200x800px
- **Service icons:** 200x200px

## 🔧 TROUBLESHOOTING

### Problem: Can't Login
- **Solution:** Check username/password
- **Solution:** Clear browser cache and try again
- **Solution:** Check if admin panel URL is correct

### Problem: Changes Not Appearing
- **Solution:** Refresh the frontend page (Ctrl+F5)
- **Solution:** Clear browser cache
- **Solution:** Wait 30 seconds for cache to clear

### Problem: Image Upload Failed
- **Solution:** Check file size (max 50MB)
- **Solution:** Check file format (JPG, PNG, WebP)
- **Solution:** Try uploading again

### Problem: Arabic Text Not Displaying Correctly
- **Solution:** Check if you're in Arabic section (AR)
- **Solution:** Verify text is in Arabic
- **Solution:** Refresh page

### Problem: Can't Find a Section
- **Solution:** Scroll down in sidebar
- **Solution:** Check if it's in English or Arabic section
- **Solution:** Use search function if available
