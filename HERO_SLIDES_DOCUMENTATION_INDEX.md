
### Step 2: Add Videos (20 minutes)
1. Click "Hero Slides (EN)"
2. Click "Edit" on each slide
3. Add 3 video URLs per slide
4. Save

**Reference:** `HERO_SLIDES_QUICK_REFERENCE_CARD.md` → "ADD VIDEOS (English Slides)"

### Step 3: Add Arabic Content (25 minutes)
1. Click "Hero Slides (AR)"
2. Click "Edit" on each slide
3. Copy Arabic text from `HERO_SLIDES_ARABIC_TRANSLATIONS_READY.md`
4. Paste into Arabic fields
5. Save

**Reference:** `HERO_SLIDES_ARABIC_TRANSLATIONS_READY.md`

### Step 4: Test (10 minutes)
1. Visit https://trq-studio.pages.dev
2. Verify slides display
3. Switch to Arabic
4. Verify Arabic content displays

**Reference:** `HERO_SLIDES_QUICK_REFERENCE_CARD.md` → "TEST ON FRONTEND"
