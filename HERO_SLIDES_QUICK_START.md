# 🎬 HERO SLIDES - QUICK START GUIDE

**Manage homepage slider with 3 videos and 3 images per slide**

---

## ⚡ 30-SECOND OVERVIEW

The Hero Slides system lets you create beautiful homepage sliders with:
- ✅ **3 videos per slide** (40 seconds each)
- ✅ **3 slide images** (main image + video posters)
- ✅ **Full text customization** (tag, title, description, buttons)
- ✅ **Bilingual support** (English & Arabic)
- ✅ **Automatic language switching** on frontend

---

## 🚀 GET STARTED IN 3 STEPS

### Step 1: Login to Admin Panel
```
URL: https://trq-studio.pages.dev/#/admin
Username: [your admin username]
Password: [your admin password]
```

- Click **"+ Add Slide"** to create new

## 🎬 MANAGING VIDEOS

### Add a Video

1. **In the Video section**, find the video field
2. **Paste video URL** (MP4 format)
3. **Add video text** (optional label)
4. **Save slide**

### Video Duration

- **Each video plays for 40 seconds**
- **3 videos = 120 seconds total** (2 minutes)
- **Then moves to next slide**

### Video Format

- **Format:** MP4
- **Codec:** H.264 video, AAC audio
- **Resolution:** 1920x1080 recommended
- **Bitrate:** 5-10 Mbps recommended

### Video Hosting

You can host videos on:
- ✅ Your own server
- ✅ Cloudflare Stream
- ✅ AWS S3
- ✅ Google Cloud Storage
- ✅ Any CDN

## 🖼️ MANAGING IMAGES

### Upload Image

1. **Click "Upload Image"** button
2. **Select image from computer**
3. **Wait for upload** (shows progress)
4. **Image URL appears** automatically
5. **Save slide**

### Image Usage

- **Main image:** Background for image-only slides
- **Video poster:** Fallback image while video loads

### Image Format

- **Format:** JPG, PNG, WebP, GIF
- **Size:** Max 5MB
- **Resolution:** 1920x1080 recommended
- **Aspect ratio:** 16:9

## 🌍 BILINGUAL MANAGEMENT

### English Content

1. **Click "Hero Slides (EN)"** in sidebar
2. **Create/edit slide** with English content
3. **Add videos** (optional)
4. **Save**

### Arabic Content

1. **Click "Hero Slides (AR)"** in sidebar
2. **Edit Arabic text** for each slide
3. **Add Arabic videos** (optional)
4. **Save**

### Language Switching

**On Frontend:**
- User clicks language switcher
- Site switches to Arabic
- All text updates to Arabic versions
- Layout switches to RTL
- Videos switch to Arabic versions (if available)

### Fallback

- If Arabic text is empty → Shows English text
- If Arabic video is empty → Shows English video

## 📋 STEP-BY-STEP: CREATE A SLIDE

### 1. Click "Hero Slides (EN)"
- Opens English hero slides section

### 2. Click "+ Add Slide"
- Opens slide editor

### 3. Fill in Basic Info
```
Tag: "TRQ Design Studio"
Title: "Elevating Spaces, Defining Luxury"
Description: "Premium interior design solutions for discerning clients."
```

### 4. Upload Image
```
Click "Upload Image"
Select image from computer
Image URL appears automatically
```

### 5. Add Videos (Optional)
```
Video 1 URL: https://example.com/video1.mp4
Video 1 Text: "Project Showcase"

Video 2 URL: https://example.com/video2.mp4
Video 2 Text: "Design Process"

Video 3 URL: https://example.com/video3.mp4
Video 3 Text: "Final Result"
```

### 6. Configure Buttons
```
Primary Button:
  Text: "VIEW PORTFOLIO"
  Link: "portfolio"

Secondary Button:
  Text: "GET IN TOUCH"
  Link: "contact"
```

### 7. Set Display Options
```
Sort Order: 1 (display order)
Active: ✓ (checked = visible)
```

### 8. Save
- Click "Save Slide"
- Slide appears on homepage immediately

## 🎯 COMMON TASKS

### Task 1: Create Slide with 3 Videos

1. Go to "Hero Slides (EN)"
2. Click "+ Add Slide"
3. Fill in text fields
4. Upload image
5. Add 3 video URLs
6. Configure buttons
7. Save

**Result:** Slide plays 3 videos (120 seconds total) then moves to next slide

### Task 2: Create Slide with Image Only

1. Go to "Hero Slides (EN)"
2. Click "+ Add Slide"
3. Fill in text fields
4. Upload image
5. Leave video fields empty
6. Configure buttons
7. Save

**Result:** Slide shows image for 5 seconds then moves to next slide

### Task 3: Add Arabic Version

1. Go to "Hero Slides (AR)"
2. Find the slide you created
3. Click "Edit"
4. Fill in Arabic text
5. Add Arabic videos (optional)
6. Save

**Result:** Arabic users see Arabic content

### Task 4: Change Slide Order

1. Go to "Hero Slides (EN)"
2. Click "Edit" on slide
3. Change "Sort Order" number
4. Save

**Result:** Slides display in new order

### Task 5: Hide a Slide

1. Go to "Hero Slides (EN)"
2. Click eye icon (👁️) on slide
3. Eye closes (👁️‍🗨️)

**Result:** Slide hidden from homepage

### Task 6: Delete a Slide

1. Go to "Hero Slides (EN)"
2. Click trash icon (🗑️) on slide
3. Confirm deletion

**Result:** Slide removed

## 🔧 TROUBLESHOOTING

### Problem: Video Not Playing

**Solution:**
- Check video URL is correct
- Check video format is MP4
- Check video is publicly accessible
- Try different video URL

### Problem: Image Not Showing

**Solution:**
- Check image URL is correct
- Check image format (JPG, PNG, WebP)
- Check image file size (max 5MB)
- Try uploading again

### Problem: Text Not Displaying

**Solution:**
- Check text is not empty
- Check text is in correct language
- Refresh page
- Clear browser cache

### Problem: Arabic Text Not Showing

**Solution:**
- Go to "Hero Slides (AR)"
- Check Arabic text is filled in
- Check Arabic text is in Arabic language
- Refresh page

### Problem: Slide Not Appearing

**Solution:**
- Check "Active" checkbox is checked
- Check sort order is set
- Refresh page
- Check browser console for errors

### Problem: Video Not Looping

**Solution:**
- Video should loop automatically
- Check video file is valid
- Try different video URL
- Check browser console for errors

## 💡 BEST PRACTICES

### Text

- ✅ Keep titles short (under 50 characters)
- ✅ Keep descriptions concise (under 150 characters)
- ✅ Use clear, compelling language
- ✅ Match tone across slides

### Videos

- ✅ Use high-quality videos
- ✅ Keep videos under 2 minutes each
- ✅ Use consistent aspect ratio (16:9)
- ✅ Optimize file size for web
- ✅ Test video playback before publishing

### Images

- ✅ Use high-resolution images (1920x1080)
- ✅ Optimize file size (under 500KB)
- ✅ Use consistent style
- ✅ Ensure text is readable over image

### Buttons

- ✅ Use action-oriented text
- ✅ Keep button text short
- ✅ Link to relevant pages
- ✅ Test button links work

### Bilingual

- ✅ Keep English and Arabic in sync
- ✅ Use professional translations
- ✅ Test both languages
- ✅ Verify RTL layout works
