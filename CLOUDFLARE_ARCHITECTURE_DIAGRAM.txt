1. IMAGE REQUEST
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ GET /images/ALULAH/Image38.png                                           │
   │                                                                          │
   │ Worker:                                                                  │
   │   1. Detect /images/ prefix                                             │
   │   2. Extract path: ALULAH/Image38.png                                   │
   │   3. Fetch from R2 bucket                                               │
   │   4. Return with cache headers (1 year)                                 │
   │                                                                          │
   │ Response:                                                                │
   │   Content-Type: image/png                                               │
   │   Cache-Control: public, max-age=31536000, immutable                    │
   │   Access-Control-Allow-Origin: *                                        │
   └──────────────────────────────────────────────────────────────────────────┘

2. API REQUEST
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ GET /api/projects                                                        │
   │                                                                          │
   │ Worker:                                                                  │
   │   1. Detect /api/ prefix                                                │
   │   2. Proxy to: https://trq-express-api.onrender.com/api/projects       │
   │   3. Add CORS headers                                                   │
   │   4. Return response                                                    │
   │                                                                          │
   │ Response:                                                                │
   │   [{ id: 1, name: "Project 1", ... }, ...]                             │
   │   Access-Control-Allow-Origin: *                                        │
   └──────────────────────────────────────────────────────────────────────────┘

3. SPA ROUTE REQUEST
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ GET /portfolio                                                           │
   │                                                                          │
   │ Worker:                                                                  │
   │   1. No matching prefix                                                 │
   │   2. Serve dist/index.html                                              │
   │   3. React Router handles /portfolio route                              │
   │                                                                          │
   │ Response:                                                                │
   │   HTML with React app                                                   │
   │   React Router renders Portfolio component                              │
   └──────────────────────────────────────────────────────────────────────────┘


╔════════════════════════════════════════════════════════════════════════════════╗
║                            DEPLOYMENT PROCESS                                  ║
╚════════════════════════════════════════════════════════════════════════════════╝

Step 1: Create R2 Buckets
   wrangler r2 bucket create trq-studio-images
   wrangler r2 bucket create trq-studio-images-preview

Step 2: Create API Token
   Cloudflare Dashboard → R2 → Settings → Create API token
   Save: Account ID, Access Key ID, Secret Access Key

Step 3: Set Environment Variables
   export CLOUDFLARE_ACCOUNT_ID="..."
   export CLOUDFLARE_R2_ACCESS_KEY_ID="..."
   export CLOUDFLARE_R2_SECRET_ACCESS_KEY="..."

Step 4: Install Dependencies
   npm install

Step 5: Upload Images to R2
   npm run upload:r2
   
   Uploads 762 image files to R2 bucket
   Sets cache headers (1 year)
   Skips fonts, videos, client logos

Step 6: Deploy Worker
   npm run deploy:worker:prod
   
   Deploys src/worker.js to Cloudflare Workers
   Binds R2 bucket
   Sets up routes

Step 7: Test
   Visit: https://trq-studio.pages.dev
   Check: Images load, API works, SPA routing works
